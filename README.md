# Challenge-1-Conversacional

## Objetivo
Este projeto tem como objetivo desenvolver um caso de uso conversacional voltado para os fãs do time de CS:GO da FURIA. A proposta central foi criar um chatbot interativo no Telegram, reunindo funcionalidades que um verdadeiro torcedor gostaria de ter para acompanhar e interagir com o time em tempo real.

## Descrição
O bot foi desenvolvido com JavaScript, utilizando a API do Telegram para criação e gerenciamento das interações. O canal escolhido para veiculação do bot foi o Telegram, com configuração inicial feita via BotFather.

Você pode testar o bot diretamente pesquisando por:
@Furia_Tigrinho_Bot no Telegram.

## Funcionalidades Propostas
Atualizações e notícias sobre o time de CS:GO da FURIA

Simulador de conversa com torcida

Mensagens motivacionais e interativas com linguagem da comunidade

Engajamento com a base de fãs durante campeonatos e eventos

## Tecnologias Utilizadas
Linguagem principal: JavaScript

Plataforma de execução: Telegram Bot API

Criação do bot: BotFather (Telegram)
